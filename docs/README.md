## Documentation Flow

```text
Foundation
  → Capability Architecture where applicable
  → PRD
  → UX
  → Parent Story Document
  → Generated Stories
  → Engineering and Development
```

ADRs record accepted architectural decisions and are referenced by the affected layers; they do not replace those layers.
